# HR-Analytics-Dashboard
## Project Overview
### This project presents an interactive HR Analytics dashboard developed using Microsoft Power BI. The dashboard provides insights into estimated annual financial cost of employee attrition to the company and which departments, job roles, cost components and salary bands driving the highest cost.
## Project Objective
- Estimate the annual financial cost of employee attrition to the company.
- Identify which departments, job roles, and salary bands drive the highest attrition cost.
- Perform exploratory data analysis (EDA) across demographics, tenure, compensation, engagement, and performance to uncover attrition patterns.
- Compare leavers vs. stayers across satisfaction, work-life balance, engagement, and manager effectiveness.
- Deliver an interactive Power BI dashboard for stakeholder exploration.
